# PDF Whiteboard / PDF 课堂白板

当前版本：**v0.2.0**。可在工具栏底部和浏览器标题查看版本号。

在 PDF 原文上书写、输入文字和绘制图形，备课时组织答案，展示时按步骤公布。无需将练习册重新排版为 PPT。

这是一个离线网页工具。打开本机 PDF 和音频即可使用，不需要账号或服务器，教材和笔记不会由本应用上传。

## 直接使用

1. 将仓库中的 `PDF课堂白板.html` 下载到本机，用新版 Edge 或 Chrome 打开。
2. 点击“打开教材文件夹”，选择 PDF 所在的目录，并允许读写。目录中有多份 PDF 时，再选择教材。默认进入展示，已保存的答案先隐藏。
3. 打开“编辑”开关可修改并保存备课笔记；关闭开关后，按空格逐步展示。

如果下载整个项目或 Release 压缩包，请先解压，再打开 HTML。日常使用不需要安装 Node.js。

项目不包含商业教材、配套音频或使用者的笔记。请使用自己有权使用的材料。详细操作见 [使用说明](使用说明.txt)。

## 功能

- 原 PDF 页面显示、页码跳转、缩放、拖动和全屏。
- 手写、透明文字编辑框、常用颜色和扩展色盘。
- 打勾、打叉、圆圈、长方形、直线和箭头。
- 备课笔记分组为展示步骤，支持预览、排序、合并、拆分和撤销。
- 随堂笔记仅在本次展示中有效；清空随堂笔记会恢复本页备课内容，并重置到第 0 步。
- 音频文件播放、大进度条、变速和循环。
- 两侧工具栏可固定、收起或自动隐藏。
- 备课标注自动保存在 PDF 同名文件夹，可随 U 盘携带；也支持导出、导入 JSON 备份。

## 笔记如何保存

| 状态 | 修改是否保存 | 重新打开 PDF 后 |
| --- | --- | --- |
| 编辑开关开启 | 自动保存备课笔记及步骤 | 恢复保存内容，答案先隐藏 |
| 编辑开关关闭 | 临时修改仅保存在内存 | 临时修改丢弃 |

通过“打开教材文件夹”打开时，在 PDF 所在目录创建同名文件夹（不含 `.pdf` 扩展名），编辑时自动保存：

```text
教材目录/
├── PDF课堂白板.html
├── 英语教材.pdf
└── 英语教材/
    └── 备课数据.json
```

数据包含各页笔迹、文字、图形、步骤分组及顺序，不修改原 PDF。备课结束时，可在“备份与设置”点击“立即保存”，等状态显示“已保存”后再安全弹出 U 盘。将 PDF 和同名文件夹一起复制到其他电脑，用白板重新选择它们所在的目录，就会读取数据；不依赖盘符、浏览器缓存或联网。HTML 可以放在其他位置，音频仍需单独携带和选择。

目录保存需要桌面版 Edge / Chrome 的文件夹读写能力，每次重新打开网页时需重新选择目录授权。浏览器无法根据单独选中的 PDF 自动取得其父目录权限，因此请使用“打开教材文件夹”。通过“仅打开 PDF”或拖入文件打开时，仍只保存在当前浏览器；不支持目录保存的浏览器可使用 JSON 导入、导出。

同名文件夹内有数据时优先读取该文件；没有文件时可恢复旧浏览器笔记，开启编辑后自动迁移到文件夹。浏览器仍保留一份本机恢复副本。文件无法读取、格式错误或不属于当前 PDF 时，会提示并阻止覆盖；写入失败时会保留浏览器恢复副本，可重试“立即保存”或导出备份。展示时的临时修改始终不写入文件夹、浏览器或导出备份。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Alt+Q | 编辑时将新增笔记“记为一步”，支持尚未完成的文字输入 |
| 空格 / ↓ / ↑ | 展示时下一步 / 下一步 / 上一步 |
| ← / → | 翻页 |
| Ctrl+Enter | 完成文字输入 |
| Ctrl+Z | 撤销 |
| P / T / E / H | 笔 / 文字 / 橡皮 / 拖动 |
| F | 全屏 |
| Esc | 取消当前文字或图形；展示时也可返回编辑 |

## 开发与构建

需要 Node.js 22.13 或更新版本，建议使用 Node.js 24 LTS。

```sh
npm install
npm test
npm run build
```

构建会将 PDF.js 阅读器、Worker、应用代码及许可证嵌入 `PDF课堂白板.html`，生成不依赖 CDN 的单文件网页。

发布新版本时，修改 `package.json` 的 `version` 并同步本文和使用说明中的版本号，再执行 `npm run build`；网页中的版本号由构建自动写入。软件版本号独立于备课数据格式版本，升级后可继续读取已有备课数据。

也可显式指定已有的 PDF.js 安装目录：

```sh
node build.mjs /path/to/pdfjs-dist
```

源文件：

| 文件 | 用途 |
| --- | --- |
| `app.mjs` | 页面操作、绘图、文字、步骤、存储和音频逻辑 |
| `viewer.template.html` | 页面结构和样式 |
| `build.mjs` | 生成离线 HTML |
| `release.mjs` | 按白名单生成干净的发布文件夹 |
| `tests/verify-whiteboard-interactions.mjs` | 模拟 DOM 的交互测试及画布检查 |

`npm test` 不使用真实教材，也不打开真实浏览器。目录保存使用模拟 File System Access API 检查保存顺序、换机恢复、旧笔记迁移、失败重试和损坏文件保护；实际目录权限及 U 盘操作仍需在桌面版 Edge / Chrome 验证。测试生成的图形预览位于 `test-output/`，不会纳入 Git。

## 发布

```sh
npm run package
```

命令先构建，再在 `release/github-upload-*` 中生成只包含发布文件的文件夹，不复制 `data/`、教材 PDF、音频或个人笔记。

贡献方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
